# Viaggio Lapponia Svedese + Norvegia Artica
## 8 giorni / 7 notti
### Periodo consigliato: 6 → 13 febbraio 2027

**Partecipanti:** 2 persone

**Budget obiettivo:** 1.500 €/persona

- Tromsø
- SPA artica

- Voli internazionali

- Volo domestico Norvegia
